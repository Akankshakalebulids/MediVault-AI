# ASDD Plan — MediVault

## Proposed Epics
1. User & Authentication
2. Medical Records
3. Medication Management
4. Appointments
5. Health Documents & Timeline
6. Administration & Security

## Initial User Stories
- As a patient, I want to register and log in so that I can access my health workspace.
- As a patient, I want to manage my profile so that my personal details remain current.
- As a patient, I want to add a medical record so that I can maintain my history.
- As a patient, I want to search records so that I can quickly find relevant information.
- As a patient, I want to add medicines so that I can track my current medications.
- As a patient, I want to set medication reminders so that I remember scheduled doses.
- As a patient, I want to record appointments so that I can track upcoming care.
- As a patient, I want to view appointment status so that I know what is confirmed or pending.
- As a patient, I want to store medical documents so that important reports are organized.
- As a patient, I want to view a health timeline so that I can understand my recorded care history.
- As a doctor, I want controlled access to shared patient records so that I can review relevant information.
- As an administrator, I want to manage users and roles so that access is controlled.
- As a user, I want secure authentication so that my account is protected.
- As a user, I want a dashboard summary so that I can see important health-management information quickly.
- As a user, I want to sign out so that my session is closed when I finish.
