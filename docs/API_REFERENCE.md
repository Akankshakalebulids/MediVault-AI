# MediVault AI — REST API Reference Documentation

This reference covers the endpoints exposed by the **Spring Boot Backend (Port 8080)** and the **FastAPI Machine Learning Inference Server (Port 8000)**.

---

## 1. Spring Boot Backend API (`http://localhost:8080`)

All responses use JSON format. Endpoints requiring user isolation accept a `userId` query parameter (defaults to `demo_user`).

### 1.1 System Health
- **`GET /api/v1/health`**
  - **Response 200 OK**:
    ```json
    {
      "status": "healthy",
      "service": "MediVault Spring Boot Backend",
      "version": "1.0.0",
      "database": "H2 (dev) / PostgreSQL (prod)",
      "uptime": "0h 15m 32s"
    }
    ```

### 1.2 Medical Records
- **`GET /api/v1/records?userId={userId}&category={category}`**
  - Returns a list of records matching the user and optional category filter.
- **`GET /api/v1/records/{id}?userId={userId}`**
  - Returns a single medical record by ID.
- **`POST /api/v1/records?userId={userId}`**
  - Body:
    ```json
    {
      "title": "Comprehensive Metabolic Panel",
      "category": "Laboratory",
      "doctor": "Dr. Ananya Mehta",
      "facility": "Metro Diagnostics",
      "date": "2026-09-28",
      "diagnosisNotes": "Normal fasting glucose (98 mg/dL)",
      "status": "Reviewed"
    }
    ```
- **`PUT /api/v1/records/{id}?userId={userId}`**
  - Partial or full updates to record fields.
- **`DELETE /api/v1/records/{id}?userId={userId}`**
  - Deletes the record (Returns `204 No Content`).

### 1.3 Medications
- **`GET /api/v1/medications?userId={userId}`**
  - Returns user's medications.
- **`POST /api/v1/medications?userId={userId}`**
  - Body:
    ```json
    {
      "name": "Vitamin D3",
      "dose": "1000 IU",
      "frequency": "Once daily",
      "time": "08:00 AM",
      "status": "Active",
      "instructions": "Take with breakfast",
      "startDate": "2026-09-15"
    }
    ```
- **`PUT /api/v1/medications/{id}?userId={userId}`**
- **`DELETE /api/v1/medications/{id}?userId={userId}`**

### 1.4 Appointments
- **`GET /api/v1/appointments?userId={userId}`**
- **`POST /api/v1/appointments?userId={userId}`**
  - Body:
    ```json
    {
      "doctorName": "Dr. Rajesh Shah",
      "specialty": "Endocrinology",
      "clinicLocation": "City Care Clinic",
      "dateTime": "2026-10-25T10:30",
      "reason": "Quarterly preventative metabolic check",
      "status": "Confirmed",
      "notes": "Fast for 8 hours prior"
    }
    ```
- **`PUT /api/v1/appointments/{id}?userId={userId}`**
- **`DELETE /api/v1/appointments/{id}?userId={userId}`**

### 1.5 Aggregated Timeline
- **`GET /api/v1/timeline?userId={userId}`**
  - Automatically aggregates records, appointments, and medication milestones chronologically.

### 1.6 User Profile
- **`GET /api/v1/profile?userId={userId}`**
- **`PUT /api/v1/profile?userId={userId}`**
  - Body:

    {

## 2. FastAPI ML Inference API (`http://127.0.0.1:8000`)

### 2.1 Model Information & Metrics
- **`GET /api/v1/model-info`**
  - Returns algorithm details, training dataset metadata, and evaluation metrics (Accuracy, ROC-AUC, F1-Score).

### 2.2 Diabetes Risk Inference
- **`POST /api/v1/predict/diabetes`**
  - Request:
    ```json
    {
      "pregnancies": 2,
      "glucose": 145.0,
      "bloodPressure": 80.0,
      "skinThickness": 22.0,
      "insulin": 110.0,
      "bmi": 28.5,
      "diabetesPedigreeFunction": 0.52,
      "age": 42
    }
    ```
  - Response 200 OK:
    ```json
    {
      "riskScore": 0.62,
      "riskPercentage": 62.0,
      "riskLevel": "Elevated Risk",
      "riskColor": "#D9383A",
      "modelAlgorithm": "Random Forest Classifier (Ensemble)",
      "contributingFactors": [
        {
          "name": "Plasma Glucose",
          "value": "145.0 mg/dL",
          "status": "Elevated",
          "clinical_note": "Values exceed normal fasting range (70-99 mg/dL)."
        }
      ],
      "disclaimer": "IMPORTANT MEDICAL NOTICE: This risk screening prediction is generated by an educational machine-learning prototype. It is strictly an informational tool and is NOT a medical diagnosis.",
      "isDiagnostic": false
    }
    ```
